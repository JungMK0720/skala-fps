SKALA 작전 개인정보처리방침

시행일: 2026년 11월 16일

SKALA 작전(이하 "게임")은 브라우저에서 하는 무료 멀티플레이 게임입니다. 게임은 계정 운영에 꼭 필요한 정보만 저장하며, 이름·이메일·전화번호·생년월일 같은 개인 식별 정보는 받지 않습니다.

1. 저장하는 정보

정보언제왜
닉네임처음 닉네임을 정할 때멀티플레이와 순위표에 이름을 보여 주기 위해
기기 식별 값(무작위로 만든 값의 해시)게임을 처음 열 때이 기기의 닉네임과 진행 상황을 찾기 위해. 원래 값은 브라우저에만 있고 서버에는 해시만 저장합니다
포인트, 가진 무기·이모트·캐릭터, 장비, 전적, 찾은 비밀 장소게임을 할 때진행 상황 저장
구글·카카오 계정의 고유 번호"계정 연결"이나 "구글로 불러오기"를 쓸 때만다른 기기에서 같은 닉네임을 불러오기 위해. 이메일·이름·프로필 사진은 받지 않고, 로그인 제공자가 준 접근 토큰도 저장하지 않습니다
코인 잔액과 사용 기록, 테스트 결제 주문 기록(주문 번호, 상품, 금액, 상태, 결제 키, 결제 수단 종류)코인 탭에서 충전·환불·사용할 때코인 지급과 환불을 정확히 처리하기 위해
건의 글과 진단 정보(화면 크기, 브라우저 종류, 모드·맵 등)건의함에 글을 보낼 때문의에 답하고 문제를 고치기 위해
IP 주소의 해시값닉네임 등록·건의 보내기 요청 때짧은 시간에 너무 많은 요청을 막기 위해. IP 원래 값은 저장하지 않습니다

멀티플레이 중의 위치와 채팅은 같은 방의 사람에게 실시간으로 전달만 하고 저장하지 않습니다.

2. 결제

코인 충전은 토스페이먼츠의 테스트 결제로, 실제로 돈이 청구되지 않습니다. 카드 번호 같은 결제 정보는 토스페이먼츠의 결제창이 처리하며 게임 서버는 받지도 저장하지도 않습니다.

3. 브라우저에 저장하는 것

게임은 브라우저 저장소(localStorage·sessionStorage)에 프로필 사본, 설정, 기기 식별 값, 로그인 진행 중의 일회용 값을 둡니다. 광고나 추적용 쿠키는 쓰지 않습니다.

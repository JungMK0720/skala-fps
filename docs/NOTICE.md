# 전체 공지 (운영자 패널)

운영자가 쓴 한 줄을 **게임 화면을 열어 둔 모든 사람의 화면 맨 위**에 띄운다. 메뉴, 연습장, 로비, 대기실, 경기 중 어디에 있든 받는다.
코드는 `js/net/notice.js`(규약·연결), `js/ui/notice.js`(화면의 띠), `dev/notice.html` + `js/admin/notice-panel.js`(운영자 패널), `tools/make-notice-key.mjs`(열쇠)다.

## 1. 보내는 법

1. 브라우저로 운영자 패널을 연다: <https://jungmk0720.github.io/skala-fps/dev/notice.html> (게임을 불러오지 않는 가벼운 페이지라 휴대폰으로도 된다)
2. **처음 한 번만** 운영자 열쇠를 넣는다. `파일 선택`으로 열쇠 파일(`notice-private-key.txt`)을 고르거나, 파일의 마지막 줄(비밀 열쇠)을 붙여 넣고 `열쇠 확인`을 누른다.
   `이 브라우저에 기억하기`가 켜져 있으면 다음부터는 넣지 않아도 된다.
3. 공지 내용을 쓰고(200자까지) `화면에 떠 있는 시간`을 고른 뒤 `공지 보내기`를 누른다(Enter도 된다).
4. 위쪽의 `접속 N명`은 지금 게임 화면을 열어 둔 사람 수다. 보내면 "접속 N명에게 보냈어요"라고 나온다.
5. 잘못 보냈으면 `공지 내리기`를 누른다. 받은 화면에서 바로 사라진다. 새 공지를 보내면 앞의 공지는 바뀐다(한 번에 하나만 떠 있다).

| 상황 | 동작 |
|---|---|
| 보낸 뒤 패널을 닫았다 | 이미 받은 화면에는 남은 시간 동안 떠 있다. 그 뒤에 접속한 사람에게는 가지 않는다 |
| 패널을 열어 둔 채 누가 새로 접속했다 | 그 사람 화면에도 뜬다. 남은 시간만큼만 떠 있다(그래도 4초는 띄운다) |
| 경기 중인 사람 | 화면 맨 위 가운데에 뜨고, 점수·타이머 줄이 그 아래로 내려간다. 조작은 막지 않는다 |
| 게임 탭을 예전에 열어 두고 새로고침하지 않은 사람 | 공지 기능이 없는 옛 화면이라 받지 못한다. 새로고침하면 받는다 |

## 2. 열쇠

공지에는 열쇠 한 쌍을 쓴다. **비밀 열쇠**는 운영자만 가지고 공지를 서명한다. **공개 열쇠**는 `js/config.js`의 `notice.key`에 있고(누구나 봐도 된다) 받는 화면이 서명을 확인하는 데 쓴다.

- 비밀 열쇠 파일은 저장소에 올리지 않는다(`.gitignore`의 `.secrets/`). 남에게 보내지 않는다.
- 운영자 패널은 넣은 열쇠를 "꺼낼 수 없는 열쇠"로 바꿔 그 브라우저에만 보관한다. 다른 PC·브라우저에서 보내려면 거기서도 열쇠 파일을 한 번 넣는다.
- 공용 PC에서 썼으면 `열쇠 지우기`를 누른다.

### 열쇠를 새로 만들 때 (잃어버렸거나 새어 나갔을 때)

```bash
node tools/make-notice-key.mjs --force
```

- 비밀 열쇠는 `.secrets/notice-private-key.txt`에만 쓰고 화면에는 찍지 않는다. 화면에 찍힌 **공개 열쇠**를 `js/config.js`의 `notice.key`에 넣고 `main`에 올린다.
- 배포가 끝나면(1~2분) 옛 열쇠로 서명한 공지는 새로고침한 화면에 더 이상 뜨지 않는다. 운영자 패널에는 새 열쇠 파일을 다시 넣는다.
- 지금 열쇠 파일의 짝인 공개 열쇠만 확인하려면 `node tools/make-notice-key.mjs --public-of .secrets/notice-private-key.txt`.

## 3. 동작 원리

```
운영자 패널 ──서명한 한 줄(presence)──▶ 중계 서버 로비 허브 ──▶ 게임 화면마다: 서명 확인 → 맨 위에 띄움
```

- **길**: 이미 쓰고 있는 Cloudflare 중계 서버의 로비 허브다. 게임 화면은 부팅할 때 로비 허브에 연결 하나를 따로 열어 둔다(게임의 로비·방 연결과 별개).
  그래서 서버를 고치거나 다시 배포할 필요가 없었고, 공지 때문에 경기 메시지가 늘지도 않는다.
- **누가 보냈는지**: 로비 허브에는 누구나 줄을 올릴 수 있다. 그래서 서버가 아니라 받는 화면이 서명(ECDSA P-256)을 확인한다. 비밀 열쇠 없이는 맞는 서명을 만들 수 없으므로 남이 올린 줄은 조용히 버려진다.
- **언제까지**: 줄에는 만든 시각과 떠 있는 시간이 서명과 함께 들어 있다. 시간이 지난 줄은 버린다(운영자 PC와 받는 PC의 시계 차이는 5분까지 봐준다).
- **접속자 수**: 게임 화면은 로비 허브에 자리 표시 한 줄을 올린다. 운영자 패널은 그 수를 센다. 탭 하나가 한 명이다.
- 자세한 규약은 `js/net/notice.js` 머리말과 `js/net/README.md` 9절.

## 4. 알아 둘 한계

- **중계 서버 전송에서만 동작한다.** `js/config.js`의 `transport`를 `'supabase'`로 되돌리면 공지는 오가지 않는다.
- **맞는 공지를 그대로 베껴 다시 올리는 것은 막지 못한다.** 다만 운영자가 정한 시간 안에서만 통하고 내용은 한 글자도 바꿀 수 없다. 이미 본 화면에는 다시 뜨지 않고, 운영자가 내린 공지는 내리기를 본 화면에 다시 뜨지 않는다.
- 패널을 닫으면 줄이 사라지므로, 오래 띄워 둘 공지(예: 30분)는 패널을 열어 둔 채로 둔다.
- 공지는 글자만 보낸다(링크·그림 없음). 받는 화면은 글자를 그대로 적기만 한다.

## 5. 시험

```bash
node --test tests/notice.test.mjs            # 서명·검증, 중계 서버 규칙, Node 중계 서버에 붙인 전체 흐름
npm run qa:hidden -- --only notice           # 실제 게임 화면과 운영자 패널을 헤드리스 브라우저로
```

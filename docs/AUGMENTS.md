# 좀비 물량 막기 증강 표

좀비 물량 막기의 레벨·증강 카드를 한곳에 모은 표다. 수치의 정본은 `js/game/horde/cards.js`(카드)와 `js/game/horde/rules.js`(경험치·보급품)이고, 고르기·동기화 규칙은 `docs/MODES.md` 13절이다.
카드를 고치면 이 표도 함께 고친다. 지금 값은 아래 명령으로 뽑아 볼 수 있다.

```bash
node -e "import('./js/game/horde/cards.js').then(m=>{for(const c of m.CARDS)console.log(c.idx,c.id,c.tier,c.name,c.retired?'(빠짐)':'',c.desc)})"
```

카드는 모두 204장이다. 제안에 나오는 것은 197장이고, 빠진 7장(`retired`)은 예전 기록·전송 번호를 읽기 위해 번호만 남아 있다(맨 아래 '제안에서 빠진 카드').

## 1. 레벨과 경험치

경험치와 레벨은 팀이 함께 쓴다(멀티도 나누지 않는다).

| 항목 | 값 | 어디 |
|---|---|---|
| 다음 레벨까지 필요한 경험치 | `10 × 레벨`: 1→2 10, 2→3 20, 3→4 30, … | `rules.js xpNeed`, `xpBase`·`xpStep` |
| 좀비 처치 | 워커·크롤러 1 · 러너·스피터·폭발 좀비 2 · 브루트 4 · 보스가 불러낸 좀비 1 | `rules.js ZOMBIE_XP` |
| 보스 처치 | 20 (보물 상자는 따로 떨어진다) | `rules.js bossXp` |
| 시간 보너스 | 40초 안에 다 잡으면 남은 1초당 1 | `rules.js timeXpMs` |
| 레벨 업 | 접속한 모두가 증강 1개씩. 여러 레벨이 한꺼번에 오르면 그만큼 이어서 | `director.js` |
| 보물 상자 | 주운 사람이 증강 1개. 첫 장은 영웅 이상 | `cards.js makeOffer({ high })` |

## 2. 제안 규칙

| 항목 | 값 |
|---|---|
| 제안 장수 | 3장, '넓은 선택'이 있으면 4장 |
| 다시 뽑기 | 제안마다 1번, '행운' 한 장마다 +1(최대 +3). 다시 뽑으면 방금 본 카드는 빠진다 |
| 등급 가중치 | 일반 55 · 희귀 28 · 영웅 13 · 전설 4 |
| 전설 | 4스테이지 전에는 전설 등급을 뽑지 않는다(뽑은 등급에 남은 카드가 없으면 남은 카드 전체에서 고르므로 그때만 예외) |
| 나오는 스테이지 | 묶음 I·II 1스테이지, III 2스테이지, IV 4스테이지부터. 특수 카드는 표의 '스테이지' 칸 |
| 같은 제안 | 같은 묶음(예: 화력 I과 화력 III)은 한 제안에 두 장 나오지 않는다 |
| 같은 등급 안 | 카드의 `w`(기본 1)만큼 나온다. 유탄 발사기·중력건 2, 바주카포 5 |
| 다 쓴 카드 | 한 장 카드는 고를 수 있는 횟수(`max`)를 다 쓰면 제안에서 빠진다. 능력치에는 상한이 없어 묶음 카드는 계속 나온다 |

고르는 방법(선택 후 확인, 1초 잠금, 멀티 20초 제한·고르는 동안 무적, 혼자면 게임 멈춤)은 `docs/MODES.md` 13절 '증강 고르기'.

**폭발 반응 장갑**(예전 가시 갑옷, id는 그대로 `thorn1`~`thorn4`): 좀비 근접·침·투사체·폭발·보스 스킬에 맞으면(피하거나 무적이면 아니다) 방장이 내 발밑에서 손 수류탄 폭발을 한 번 계산한다. 수류탄을 쓰지 않고, 아군 피해는 없다.
피해는 손 수류탄과 같은 거리 감쇠(반경 6 m, 0.8 m 안은 최대)에 수류탄 배율 10·모든 피해·수류탄 피해 증강이 붙고, 폭발 반경 증강만큼 넓어지며, 화염·빙결·어그로 수류탄 증강도 붙는다. 장판(산성·불·서리) 피해에는 터지지 않는다.
값은 초당 터지는 횟수(I 0.25 · II 1/3 · III 0.5 · IV 1)라 여러 장이면 더해진다(IV 두 장이면 0.5초에 한 번). `director.js reactiveBlast`.

💣 = 수류탄 증강. 고르면 **최대 수류탄 +2와 가득 채움**이 함께 붙는다(수류탄 주머니는 표의 값만큼).

## 5. 상한 없음

능력치에는 상한이 없다(2026-11-19, `cards.js computePerks`는 더하기만 한다). 예외는 회피(90%)와 받는 피해 감소(90%)다. 음수가 될 수 있는 값만 하한이 있다: 최대 체력 % −60%, 이동 속도 −30%, 재장전 속도 −50%.
최대 체력은 `(100 + 더한 체력) × (1 + 체력 %)`이고 20 아래로 내려가지 않는다(`perkMaxHp`).

계산이 깨지지 않게 하는 쪽의 한계는 남아 있다. 이 값을 넘게 쌓아도 효과는 더 오르지 않는다.

| 능력치 | 실제로 쓰는 한계 | 어디 |
|---|---|---|
| 회피(`dodge`) | 90% | `director.js hurtPlayer DODGE_CAP` |
| 받는 피해 감소(방탄복·벙커·불굴 `armor` + 방패 칼 `guard`, 합친 값) | −90% | `director.js hurtPlayer REDUCE_CAP` |
| 냉각(`slow`) | 느려짐 60%(시간은 계속 늘어난다) | `director.js hurtZombie` |
| 탄퍼짐·반동(`spread`·`recoil`) | 최소 20%는 남는다 | `client.js modsFromPerks` |
| 탄약 절약(`thrift`) | 90% | `logic.js setMods` |
| 연사·탄창·재장전·꺼내기 배율 | ×20 | `logic.js setMods` |
| 제안 장수(`offers`) | 6장 | `cards.js makeOffer` |
| 검기(`wave`) | 화면이 40 m에서 자른다 | `world.js` |

한계가 없는 능력치: 구급 상자 확률이 100%를 넘으면 탄창이 떨어지지 않는다(`rollDrop`이 구급 상자를 먼저 굴린다). 반사 신경이 쌓이면 맞은 뒤 무적이 그만큼 길어진다.

## 6. 제안에서 빠진 카드

번호(`idx`)와 id는 그대로 남아 예전 기록과 전송 값을 읽는다. 제안에는 나오지 않는다.

| idx | id | 이름 | 빠진 까닭 |
|---|---|---|---|
| 45~47 | `hands2`~`hands4` | 빠른 손 | 재장전 −50% 한 장(최대 2번)으로 합침 |
| 105~107 | `pierce2`~`pierce4` | 관통탄 | 무제한 관통 한 장으로 합침 |
| 184 | `rearm` | 무기 교체권 | 주무기를 바꾸는 증강 삭제(일곱 번째 요청) |

새 카드는 `cards.js`의 `ADDED` 끝에만 붙인다. 카드 순서가 전송 번호라, 중간에 넣으면 예전 카드의 번호가 바뀐다.

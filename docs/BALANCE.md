## 탄약

상점 가격이 1,200 P 이상인 총(LN-3, DM-4, T-2, H-50)은 프리미엄이라 예비 탄약이 무제한이다. 탄창과 재장전은 그대로라 화력이 늘지는 않고, 오래 버틸 때만 차이가 난다. 나머지 총은 탄창 + 예비 2탄창이 전부이고 다음 스폰에 다시 찬다. 탄을 다 쓰면 권총과 칼로 싸우거나, 다른 사람이 죽으면서 G로 버린 주무기를 주워 쓴다. 주운 총은 남은 탄약 그대로 받고 그 목숨에만 쓴다.

## 3. 왜 이 수치인가

- **라이플은 어느 거리든 머리 1발이다.** 조준을 잘한 보상이 거리 때문에 사라지지 않게 했다(`head ≥ 100`, `headIgnoresFalloff`). 감쇠는 몸·다리·손발에만 걸리고, 라이플끼리의 차이는 몸통 TTK와 반동으로 낸다.
- **저격 반샷.** 머리·몸·다리는 1발이지만 손끝과 발은 표의 값만 들어간다. 스친 타격까지 즉사면 엄폐 뒤로 살짝 드러난 부위가 곧 죽음이 되기 때문이다. 손은 손끝만 스칠 때만 반샷이고, 손 뒤에 몸통이 있으면 몸통 1발 킬이다. 최소 피해나 무조건 1발 킬 같은 보정은 없고, 표의 값이 곧 결과다.
- **퀵스코프.** 줌 진행도가 `accurateAt`을 넘는 순간부터 정조준이다. 위력은 그대로고 정확도만 달라진다. '반샷'과 다른 개념이다.
- **비싼 무기가 더 세지는 않다.** 기본 지급 RX-4·SK-7·P-9는 어느 상황에서나 쓸 수 있다. 상점 무기는 강점을 얻는 만큼 약점도 분명한 옆그레이드다. 시작 포인트 500으로는 M-44만 바로 살 수 있다.
- **점사의 쉬는 시간.** BR-3의 `fireInterval`(0.36초)은 점사가 끝난 뒤 쉬는 시간이다. 점사 안의 탄 간격은 `burst.gap`(0.065초)이고, 방장의 연사 검증은 더 짧은 쪽인 `minShotInterval(id)`를 기준으로 삼는다.

## 4. 어디를 고치나

전부 `js/weapons/defs.js`의 `WEAPONS[id]`다. 카드 문구(`stats`)는 숫자에서 만들어지므로 따로 고치지 않는다.

| 바꾸고 싶은 것 | 필드 | 같이 볼 것 |
|---|---|---|
| 몸통 TTK | `damage.body`, `fireInterval`과 `rpm` | 두 연사 값은 함께 고친다 |
| 먼 거리 위력 | `falloff {start, end, min}` | 사거리는 `maxRange`. 방장도 이 값으로 거부한다 |
| 머리 1발 | `damage.head`, `headIgnoresFalloff` | `kind: 'rifle'`은 머리 100 이상을 유지한다 |
| 반샷 | `damage.hand`, `damage.foot` | 저격총에서만 반샷으로 친다(`isHalfShot`) |
| 점사 | `burst {count, gap}`, `fireInterval`, `rpm` | `rpm`은 쉬는 시간까지 넣은 실효 연사다 |
| 산탄 | `pellets`, `damage`(펠릿당), `spread.hip` | 위 한 방 확률이 크게 바뀐다 |
| 반동 | 파일 위쪽 `*_PATTERN`, `recoil {adsMul, maxPitch, maxYaw, recoverDelay, recoverRate, patternRecover}` | LN-3은 RX-4의 약 40%를 유지한다 |
| 탄퍼짐 | `spread {hip, ads, move, adsMove, air, adsAir, bloomPerShot, bloomMax, bloomDecay, adsBloomMul, max}` | |
| 줌 | `zoom {mag 또는 levels, inTime, outTime, levelTime, accurateAt, moveMul, unzoomOnFire}` | `levels`가 있으면 우클릭으로 단계가 돈다 |
| 칼 | `melee {slash, stab}`의 `damage, cooldown, windup, range, arc` | |
| 탄약·재장전 | `mag`, `reserve`, `reload`, `reloadEmpty`, `drawTime` | |
| 이동 속도 | `moveMul`, `zoom.moveMul` | |
| 상점 | `price`, `bars` | `bars`는 손으로 맞춘다 |

수치를 바꾸면 `node --test tests/weapons.test.mjs`가 실패한다. 의도한 변경이면 그 파일의 `TABLE`, `docs/DESIGN.md` 3.2절, 이 문서의 표를 함께 고친다. 방장 판정(`match.js`)과 봇(`bots.js`)은 DESIGN 3.4절과 6절대로 `defs`에서 읽으므로 수치를 따로 적지 않는다.

# 이모트 음악

이모트 11종의 소리는 모두 게임 안에서 합성합니다. 음표·리듬 표를 `js/fx/audio.js`의 `EMOTE_DEFS`에 직접 적고, 브라우저가 처음 쓸 때 한 번 렌더해 캐시합니다. 외부 음원 파일(mp3·wav 등)은 쓰지 않고 내려받지도 않습니다.

예전에 쓰던 음원 묶음(`audio/emotes/*.bin`)과 그 암호화 도구는 출처와 권리 기록이 없어서 지웠습니다(docs/PRODUCT_PLAN.md 2.1절). 저장소 기록에서 지우는 일은 2.2절에 따로 있습니다.

## 박자 맞추기

- 춤 박자와 음악 템포는 같은 값 하나(`js/core/consts.js` `EMOTES[].bpm`)를 씁니다. 춤은 `js/engine/emoteanim.js`의 키프레임(`beats` 박 한 주기)이 이 템포로 돕니다.
- 음악 루프 길이(`bars` × 4박)는 춤 한 주기의 정수 배로 정합니다. 그래야 루프가 돌 때마다 춤과 다시 맞습니다. `tests/emotes.test.mjs`가 `EMOTE_LOOP_BEATS`로 확인합니다.
- 춤에서 크게 움직이는 박(위 표)에 소리를 둡니다. 키프레임의 `t`(박)와 곡의 칸(`16분음표`, 한 박 = 4칸)을 같은 기준으로 적습니다.

## 새 곡을 쓰거나 고칠 때

1. `js/fx/audio.js`의 `EMOTE_DEFS`에서 그 이모트 항목을 고칩니다. 쓸 수 있는 악기는 `kit`(킥·스네어·박수·하이햇·흔들개·림·플럭·마림바·지속음)과 합성기 `S.tone`·`S.noise`·`S.ring`입니다.
2. 직접 지은 선율과 리듬만 씁니다. 기존 곡의 멜로디·리듬·가사를 옮기지 않습니다.
3. 템포를 바꾸면 `EMOTES[].bpm` 하나만 고칩니다. 춤과 음악이 함께 바뀝니다.
4. `npm test`로 박자 맞물림을 확인하고, `dev/fx-demo.html`의 이모트 버튼이나 상점의 이모트 탭 `▶ 듣기`로 들어 봅니다.

## 외부 음원을 다시 쓰려면

지금 게임에는 외부 음원을 읽는 코드가 없습니다. 권리를 산 음원을 쓰기로 하면 먼저 `docs/ASSETS.md`에 출처 주소, 라이선스, 내려받은 날짜를 적고, 그다음에 읽는 코드를 새로 넣습니다. 출처를 적을 수 없는 파일은 넣지 않습니다.

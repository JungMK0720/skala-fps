# 이모트 BGM 넣는 방법

이모트 11종 가운데 6종(L을 가져가, 야채, 크리스 크로스, 크림치즈 허니, 당신에게서, 셀카)은 `audio/emotes/`의 음원 묶음(`.bin`)으로 나오고, 나머지 5종은 게임 안에서 만든 합성음으로 나옵니다. 묶음을 못 읽으면(파일 없음, 오래된 브라우저, 보안 연결이 아님) 그 이모트도 합성음으로 돌아갑니다.

## 음원 묶음

원본 음원(mp3 등)은 저장소에 올리지 않습니다(`.gitignore`). 저장소에는 `tools/pack-emote-audio.mjs`로 묶은 파일만 둡니다.

- **형식:** `SKE1` 머리 + IV 12바이트 + AES-256-GCM 암호문·태그. 풀면 모노 32 kHz 16비트 WAV 한 소절입니다. 키와 형식은 `js/fx/emote-key.js`에 있습니다.
- **브라우저:** `js/fx/audio.js`가 manifest의 `"enc": true` 항목을 WebCrypto로 풀어 디코드합니다. 바뀐 파일은 GCM 태그에서 걸러져 합성음으로 돌아갑니다.
- **한계:** 키가 사이트 코드에 있으므로 DRM이 아닙니다. 파일 주소를 알아도 바로 들을 수 없게 하는 정도입니다. 코드를 읽고 직접 푸는 것까지 막지는 못합니다.

## 순서

1. 원본 파일을 저장소 밖 한 폴더에 둡니다. 같은 소절이 쉼과 함께 몇 번 반복된 파일이면 됩니다.
2. `tools/pack-emote-audio.mjs`의 `SOURCES` 표에 이모트 id, 원본 파일 이름, 한 소절 길이(초, 끝의 쉼 포함)를 적습니다.
3. 묶습니다. ffmpeg가 필요합니다.

   ```bash
   node tools/pack-emote-audio.mjs <원본 폴더>
   FFMPEG=<ffmpeg 경로> node tools/pack-emote-audio.mjs <원본 폴더> takeL   # 하나만, ffmpeg가 PATH에 없을 때
   ```

   맨 앞 한 소절을 잘라 `audio/emotes/<id>.bin`을 쓰고 `manifest.json`에 `{ "file": "<id>.bin", "enc": true, "loopStart": 0, "loopEnd": <소절 초> }`를 적습니다. 두 번째 소절이 첫 소절과 다르면 경고합니다. 같은 원본을 다시 묶으면 같은 파일이 나옵니다.
4. 춤 박자를 소절에 맞춥니다. `js/core/consts.js` `EMOTES`의 `bpm`은 `perBar(박 수, 소절 초)`로 적어서 한 소절에 정수 박이 들어가게 합니다. 합성음(`js/fx/audio.js`)도 같은 값을 씁니다. `tests/emotes.test.mjs`가 소절과 박자의 맞물림을 확인합니다.
5. 로컬에서 확인합니다. `npm run serve`로 띄우고 게임을 연 뒤 한 번 클릭합니다. 콘솔(F12)에 `[fx] 이모트 음원 — 파일: takeL, …`가 나오면 파일을 읽은 것입니다. 상점의 이모트 탭에서 `▶ 듣기`로도 들어 볼 수 있습니다.

## manifest 항목

| 칸 | 필수 | 뜻 |
|---|---|---|
| `file` | 예 | `audio/emotes/` 기준 파일 이름. 하위 폴더는 되지만 `..`과 주소(URL)는 안 됩니다 |
| `enc` | 아니오 | `true`면 음원 묶음으로 보고 풀어서 씁니다. 없으면 그대로 디코드합니다(mp3·wav) |
| `gain` | 아니오 | 음량 배율. 기본 1, 최대 4. 파일 음량을 합성음에 맞춘 뒤 곱합니다 |
| `loopStart` | 아니오 | 반복 구간 시작(초). 처음에는 0초부터 들려주고 그 뒤로 이 구간을 반복합니다 |
| `loopEnd` | 아니오 | 반복 구간 끝(초). 없으면 파일 끝까지입니다 |

## 주의점

- **권리:** 저장소가 공개라서 묶음 파일도 누구나 내려받을 수 있습니다. 사용 권리를 확인한 음원만 묶어 올리세요.
- **크기:** 모든 플레이어가 내려받습니다. 묶음 하나를 1 MB 아래로 둡니다(지금 6개 합계 약 630 KB). 8 MB나 60초를 넘으면 쓰지 않고 합성음으로 돌아갑니다.
- **다른 사람에게도 들립니다.** 내 이모트 소리는 주변 플레이어에게 작게 들립니다.
- **파일을 뺄 때:** manifest 항목도 함께 지웁니다. 항목만 남으면 브라우저 콘솔에 404가 뜹니다(게임은 합성음으로 계속됩니다).
- **전부 되돌릴 때:** `manifest.json` 파일을 지우지 말고 내용을 `{}`로 둡니다.

자세한 동작은 [js/fx/README.md](../js/fx/README.md)의 "음원 교체 방법"에 있습니다.

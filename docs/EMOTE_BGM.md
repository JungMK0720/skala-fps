# 이모트 BGM 넣는 방법

이모트 8종은 지금 게임 안에서 만든 합성음으로 나옵니다. mp3 파일을 넣으면 그 이모트만 파일로 바뀌고, 나머지는 합성음 그대로입니다. 코드는 고치지 않습니다.

## 순서

1. 음원 파일을 `audio/emotes/`에 넣습니다. 파일 이름은 자유지만 이모트 id와 같게 하면 알아보기 쉽습니다. 예: `takeL.mp3`
2. 같은 폴더의 `audio/emotes/manifest.json`에 항목을 적습니다.

   ```json
   {
     "takeL": { "file": "takeL.mp3" },
     "tango": { "file": "tango.mp3", "gain": 0.8, "loopStart": 1.25, "loopEnd": 21.25 }
   }
   ```

3. 로컬에서 확인합니다. `npm run serve`로 띄우고 게임을 연 뒤, 아무 곳이나 한 번 클릭합니다. 연습장에 들어가 멈춘 채로 B를 누르고 있다가 이모트를 고르고 떼면 재생됩니다. 콘솔(F12)에 `[fx] 이모트 음원 — 파일: takeL`처럼 나오면 파일을 읽은 것입니다. 첫 재생이 합성음이면 파일을 다 읽기 전에 시작한 것이니 한 번 더 해 보세요.
4. 커밋하고 `main`에 올리면 GitHub Pages가 1~2분 뒤에 다시 배포합니다.

## 이모트 id

| id | 화면 이름 | 재생 | 춤 박자(BPM) |
|---|---|---|---|
| `takeL` | L을 가져가 | 반복 | 150 |
| `veggie` | 새싹 댄스 | 반복 | 73.7 |
| `sideToSide` | 사이드 스텝 | 반복 | 129.7 |
| `crissCross` | X 점프 | 반복 | 104.9 |
| `tango` | 탱고 | 반복 | 96 |
| `cheer` | 환호 박수 | 반복 | 128 |
| `salute` | 경례 | 한 번 | 없음 |
| `wave` | 손 흔들기 | 한 번 | 없음 |

곡의 박자가 춤 박자와 같으면 동작이 음악에 맞습니다.

## manifest 항목

| 칸 | 필수 | 뜻 |
|---|---|---|
| `file` | 예 | `audio/emotes/` 기준 파일 이름. 하위 폴더는 되지만 `..`과 주소(URL)는 안 됩니다 |
| `gain` | 아니오 | 음량 배율. 기본 1, 최대 4. 파일 음량을 합성음에 맞춘 뒤 곱합니다 |
| `loopStart` | 아니오 | 반복 구간 시작(초). 처음에는 0초부터 들려주고 그 뒤로 이 구간을 반복합니다 |
| `loopEnd` | 아니오 | 반복 구간 끝(초). 없으면 파일 끝까지입니다 |

## 파일 조건

- **형식:** mp3를 권장합니다. 브라우저가 읽을 수 있으면 되지만, 파일 하나를 1 MB 이하로 맞추세요. 모든 플레이어가 내려받습니다.
- **길이:** 반복형은 박자에 맞춰 자른 8~30초, 한 번형(`salute`, `wave`)은 3초 이하가 좋습니다.
- **한도:** 8 MB나 60초를 넘으면 그 파일은 쓰지 않고 합성음으로 돌아갑니다.

## 주의점

- **저작권:** 저장소가 공개라서 파일을 올리는 순간 누구나 내려받을 수 있습니다. 직접 만들었거나 배포 권리를 확인한 음원만 올리세요. 유튜브나 게임에서 추출한 음원, 출처를 모르는 mp3는 쓰지 않습니다.
- **다른 사람에게도 들립니다.** 내 이모트 소리는 주변 플레이어에게 작게 들립니다.
- **파일을 뺄 때:** manifest 항목도 함께 지웁니다. 항목만 남으면 브라우저 콘솔에 404가 뜹니다(게임은 합성음으로 계속됩니다).
- **전부 되돌릴 때:** `manifest.json` 파일을 지우지 말고 내용을 `{}`로 둡니다.

자세한 동작은 [js/fx/README.md](../js/fx/README.md)의 "음원 교체 방법"에 있습니다.

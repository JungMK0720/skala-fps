# SKALA FPS

브라우저에서 바로 하는 빠른 FPS입니다. 빌드 없이 three.js와 ES 모듈로 돌아가고, GitHub Pages에 그대로 올릴 수 있습니다.

## 실행

```bash
npm run serve
```

브라우저에서 <http://localhost:8080/>을 엽니다. Node 20 이상이 필요하고 설치할 패키지는 없습니다. 8080 포트가 이미 쓰이고 있으면 `node tools/serve.mjs 8123`처럼 포트를 지정합니다.

처음 실행하면 닉네임을 정합니다. 닉네임은 마이페이지에서 언제든 바꿀 수 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 스페이스 | 점프. 꾹 누르면 착지할 때마다 자동으로 다시 뜁니다 |
| 공중에서 A/D + 마우스 | 같은 쪽으로 좌우로 흔들면 가속됩니다 |
| 좌클릭 / 우클릭 | 사격 / 줌. 2단 줌 저격총은 누를 때마다 다음 단계로 바뀝니다 |
| R | 재장전 |
| 1~4, 휠 | 무기 교체 |
| F | 무기 살펴보기 |
| Ctrl 또는 C | 앉기 |
| Shift | 천천히 걷기 |
| B | 이모트 휠 |
| Tab | 점수판 |
| Esc | 일시정지 |

## 게임 규칙

- **클래식**: 모든 무기를 씁니다.
- **칼전**: 칼만 씁니다. 나이프는 빠르고 짧고, 카타나는 길고 느립니다.
- **스나전**: 저격총과 칼만 씁니다.
- 각 규칙은 팀전(5판 3선승)과 개인전(목표 킬) 중에서 고릅니다.
- 라이플은 머리에 맞으면 거리와 상관없이 1발에 죽습니다.
- 저격총은 손끝이나 발에 맞으면 반샷이라 죽지 않습니다.
- 경기와 비밀 스팟으로 포인트를 모아 상점에서 무기를 삽니다. 예: 2단 줌 저격총, 연사형 라이플, 저반동 헤드라인 라이플.

## 맵

| 맵 | 규칙 | 특징 |
|---|---|---|
| 항구 골목 | 클래식, 칼전 | 골목 3개가 작은 광장으로 모이는 좁은 맵 |
| 벚꽃 도장 | 칼전 | 칼전 전용 안뜰, 발판으로 가는 비밀 지붕 |
| 협곡 저격장 | 스나전 | 긴 시야선, 저격 둥지, 포털로 가는 비밀 관측소 |
| 넥서스 | 전체 | 칼전 구덩이, 라이플 골목, 저격 탑을 합친 통합 맵 |
| 원유 부두, VLCC 갑판 | 클래식, 스나전 | 기존 맵 |
| 탱크 팜 | 클래식 | 기존 맵 |

## 배포

**GitHub Pages**: 저장소 **Settings > Pages**에서 **Deploy from a branch**, `main`, `/ (root)`를 고릅니다. 빌드 과정은 없습니다.

**Supabase**: 멀티플레이와 전역 닉네임 중복 검사에 필요합니다. 절차는 [docs/SUPABASE_SETUP.md](docs/SUPABASE_SETUP.md)에 있습니다. `js/config.js`가 비어 있으면 연습장만 오프라인으로 동작합니다.

npm run check

## 저작권

코드, 모델, 텍스처, 소리는 모두 직접 만들었고 외부 이미지나 음원을 쓰지 않습니다. 이모트 음원을 넣고 싶으면 권리가 있는 파일만 `audio/emotes/`에 넣고 `manifest.json`에 등록합니다. 맵은 상용 게임의 구조를 옮기지 않은 오리지널입니다.

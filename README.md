# SKALA 작전

브라우저에서 바로 하는 빠른 FPS입니다. 빌드 없이 three.js와 ES 모듈로 돌아가고, GitHub Pages에 그대로 올릴 수 있습니다.

**플레이: <https://jungmk0720.github.io/skala-fps/>**

## 실행

```bash
npm run serve
```

브라우저에서 <http://localhost:8080/>을 엽니다. Node 20 이상이 필요하고 설치할 패키지는 없습니다. 8080 포트가 이미 쓰이고 있으면 `node tools/serve.mjs 8123`처럼 포트를 지정합니다.

처음 실행하면 닉네임을 정합니다. 닉네임은 마이페이지에서 언제든 바꿀 수 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 스페이스 | 점프. 꾹 누르면 착지할 때마다 자동으로 다시 뜁니다 |
| 공중에서 A/D + 마우스 | 같은 쪽으로 좌우로 흔들면 가속됩니다 |
| 좌클릭 / 우클릭 | 사격 / 줌. 2단 줌 저격총은 누를 때마다 다음 단계로 바뀝니다 |
| R | 재장전 |
| 1~4, 휠 | 무기 교체 |
| F | 무기 살펴보기 |
| G | 들고 있는 주무기·보조무기 버리기 |
| E | 폭탄 설치·해체(폭파 미션, 누르고 있기) |
| Ctrl 또는 C | 앉기 |
| Shift | 천천히 걷기 |
| B | 이모트 휠 |
| Enter | 채팅(멀티플레이 경기 중) |
| Tab | 점수판 |
| Esc | 일시정지 |

**휴대폰**: 같은 주소를 휴대폰 브라우저에서 열면 터치 조작으로 바뀝니다. 가로로 돌려서 합니다. 왼쪽 화면을 끌면 이동, 오른쪽 화면을 끌면 시점이고, 발사·조준·점프·앉기·장전·이모트·점수·일시정지는 화면의 버튼으로, 무기는 아래 칸을 눌러 바꿉니다. 이모트 버튼을 한 번 누르면 휠이 열린 채로 남아 원하는 칸을 누르면 됩니다(누른 채 끌어서 골라도 됩니다). 멀티플레이 경기에서는 채팅 버튼이 생기고, 빠른 문장을 누르면 바로 보냅니다. 죽은 뒤에는 화면의 안내를 눌러 총을 버립니다. 폭파 미션에서는 구역 안이나 폭탄 근처에서만 설치/해체 버튼이 나타나고, 누르고 있으면 됩니다. PC에서 미리 보려면 주소 뒤에 `?touch=1`을 붙입니다.

## 게임 규칙

- **클래식**: 모든 무기를 씁니다.
- **칼전**: 칼만 씁니다. 기본 칼은 호크빌 나이프이고, 탄토·구르카·카타나는 상점에서 삽니다.
- **스나전**: 저격총과 칼만 씁니다.
- 각 규칙은 팀전(5판 3선승)과 개인전(목표 킬) 중에서 고릅니다. 팀은 블루와 레드입니다.
- **폭파 미션**: 공격·수비로 나뉘는 팀 모드입니다(클래식 규칙, 5판 3선승, 라운드 1:40, 라운드 중 부활 없음, 2라운드 뒤 공수 교대). 공격 팀 한 명이 폭탄을 들고, A·B 구역(수비 팀의 컴퓨터가 있는 곳) 안에서 멈춘 채 E를 3초 누르면 설치합니다. 설치 35초 뒤 터지면 공격 승입니다. 수비 팀은 폭탄 1.5 m 안에서 E를 5초 눌러 해체하면 이깁니다. 설치 전에 공격 팀이 전멸하거나 설치 없이 시간이 끝나도 수비 승, 수비 팀이 전멸하면 공격 승입니다. 폭탄을 든 사람이 쓰러지면 그 자리에 떨어지고 공격 팀원만 주울 수 있습니다.
- 라이플은 머리에 맞으면 거리와 상관없이 1발에 죽습니다.
- 상점 가격이 1,200 P 이상인 프리미엄 총은 예비 탄약이 무제한이고, 나머지 총은 탄창 + 예비 2탄창이 전부입니다.
- G를 누르면 손에 든 주무기·보조무기를 버립니다(칼로 바꿔 더 빨리 달릴 수 있습니다). 총을 든 채 죽으면 그 총이 떨어지고, 그 칸이 빈 사람이 닿으면 주워서 남은 탄약 그대로 씁니다. 휴대폰은 무기 칸을 길게 누릅니다.
- 저격총은 손끝이나 발에 맞으면 반샷이라 죽지 않습니다.
- 경기와 비밀 스팟으로 포인트를 모아 상점에서 무기와 이모트를 삽니다. 예: 2단 줌 저격총, 연사형 라이플, 저반동 헤드라인 라이플, 셀카 이모트.
- 이모트 휠(B) 8칸에 무엇을 둘지는 상점의 이모트 탭에서 고릅니다.
- 처음에는 기본 캐릭터(보병)로 시작하고, 상점의 캐릭터 탭에서 포인트로 정찰병·공병·통신병·사막 레인저·야간 작전병·중장갑병(300~2,000 P)을 사서 입습니다. 모양만 다르고 몸 크기와 판정은 모두 같으며, 전투복은 팀 색이라 어느 캐릭터든 팀이 잘 보입니다. 다른 사람에게도 내 캐릭터로 보입니다.

## 맵

| 맵 | 규칙 | 특징 |
|---|---|---|
| 빨랫줄 옥상 | 칼전 | 칼전 기본 맵. 22×24 m 밤 옥상, 옥탑방과 빨랫줄 이불 사이에서 몇 초 만에 맞붙는다 |
| 선인장 온실 | 칼전 | 24×20 m 한낮의 유리 온실, 선인장 화단과 가운데 분수 단상 |
| 항구 골목 | 클래식, 칼전 | 골목 3개가 작은 광장으로 모이는 좁은 맵 |
| 벚꽃 도장 | 전체 | 탑을 둘러싼 안뜰 통합 맵, 발판으로 가는 비밀 지붕 |
| 협곡 저격장 | 스나전 | 긴 시야선, 저격 둥지, 포털로 가는 비밀 관측소 |
| 넥서스 | 전체 | 칼전 구덩이, 라이플 골목, 저격 탑을 합친 통합 맵 |
| 원유 부두, VLCC 갑판 | 클래식, 스나전 | 기존 맵 |
| 탱크 팜 | 클래식 | 기존 맵 |
| 중계 기지 | 클래식(폭파 미션) | 구름 위 산꼭대기 통신 중계 기지. 서쪽 하역장(공격)에서 능선길·발전기 마당·케이블 통로가 서버 홀(A)과 안테나 마당(B)으로 이어진다. 팀전·개인전도 됩니다 |

## 배포

**GitHub Pages**: `main`의 루트를 그대로 배포합니다. 빌드 과정은 없고, `main`에 올리면 1~2분 뒤 반영됩니다.

**Supabase**: 멀티플레이와 전역 닉네임 중복 검사에 씁니다. 운영 프로젝트는 서울 리전의 `skala-fps`이고, 절차는 [docs/SUPABASE_SETUP.md](docs/SUPABASE_SETUP.md)에 있습니다. `js/config.js`를 비우면 연습장만 오프라인으로 동작합니다.

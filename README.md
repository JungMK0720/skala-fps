# SKALA 작전

브라우저에서 바로 하는 빠른 FPS입니다. 빌드 없이 three.js와 ES 모듈로 돌아가고, GitHub Pages에 그대로 올릴 수 있습니다.

**플레이: <https://jungmk0720.github.io/skala-fps/>**

## 실행

```bash
npm run serve
```

브라우저에서 <http://localhost:8080/>을 엽니다. Node 20 이상이 필요하고 설치할 패키지는 없습니다. 8080 포트가 이미 쓰이고 있으면 `node tools/serve.mjs 8123`처럼 포트를 지정합니다.

처음 실행하면 닉네임을 정합니다. 닉네임은 마이페이지에서 언제든 바꿀 수 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 스페이스 | 점프. 꾹 누르면 착지할 때마다 자동으로 다시 뜁니다 |
| 공중에서 A/D + 마우스 | 같은 쪽으로 좌우로 흔들면 가속됩니다 |
| 좌클릭 / 우클릭 | 사격 / 줌. 2단 줌 저격총은 누를 때마다 다음 단계로 바뀝니다 |
| R | 재장전 |
| 1~4, 휠 | 들고 있는 무기 바꾸기 |
| N | 무기 교체 창(라운드가 시작되기 전 대기 시간). 목록에서 무기를 누르면 바로 바뀝니다 |
| F | 무기 살펴보기 |
| G | 들고 있는 주무기·보조무기 버리기 |
| E | 폭탄 설치·해체(폭파 미션, 누르고 있기) |
| Ctrl 또는 C | 앉기 |
| Shift | 천천히 걷기 |
| B | 이모트 휠 |
| Enter | 채팅(멀티플레이 경기 중). 팀 경기에서는 입력칸에서 Tab을 눌러 전체 ↔ 팀 채팅을 바꿉니다 |
| Tab | 점수판 |
| F11 | 전체 화면 · 브라우저 단축키 잠금. Ctrl+W(탭 닫기)·Ctrl+T·Tab·Esc를 게임이 받습니다(크롬·엣지) |
| Esc | 일시정지. 전체 화면에서 나가려면 길게 누릅니다 |

앉기 키가 Ctrl이라 창 화면에서 앉은 채 앞으로 가면(Ctrl+W) 브라우저가 탭을 닫으려 합니다. F11이나 설정·일시정지 메뉴의 "전체 화면"을 켜면 이런 키를 게임이 받습니다. 전체 화면을 쓰지 않을 때는 C 키로 앉으세요.

**휴대폰**: 같은 주소를 휴대폰 브라우저에서 열면 터치 조작으로 바뀝니다. 가로로 돌려서 합니다. 왼쪽 화면을 끌면 이동, 오른쪽 화면을 끌면 시점이고, 발사·조준·점프·앉기·장전·이모트·점수·일시정지는 화면의 버튼으로, 무기는 아래 칸을 눌러 바꿉니다. 이모트 버튼을 한 번 누르면 휠이 열린 채로 남아 원하는 칸을 누르면 됩니다(누른 채 끌어서 골라도 됩니다). 멀티플레이 경기에서는 채팅 버튼이 생기고, 빠른 문장을 누르면 바로 보냅니다. 죽은 뒤에는 화면의 안내를 눌러 총을 버립니다. 라운드가 시작되기 전에는 "눌러서 무기 교체!" 안내를 눌러 무기를 바꿉니다. 폭파 미션에서는 구역 안이나 폭탄 근처에서만 설치/해체 버튼이 나타나고, 누르고 있으면 됩니다. PC에서 미리 보려면 주소 뒤에 `?touch=1`을 붙입니다.

## 게임 규칙

- **클래식**: 모든 무기를 씁니다.
- **칼전**: 칼만 씁니다. 기본 칼은 호크빌 나이프이고, 탄토·구르카·카타나는 상점에서 삽니다.
- **스나전**: 저격총과 칼만 씁니다.
- 각 규칙은 팀전(5판 3선승)과 개인전(목표 킬) 중에서 고릅니다. 팀은 블루와 레드입니다. 멀티 개인전의 목표 킬은 방장이 방을 만들 때나 대기실에서 5~20킬 중에서 고릅니다(기본 20킬). 목표 킬이 짧은 판은 승리 보상도 비례해 줄어듭니다(10킬 판은 절반).
- **폭파 미션**: 공격·수비로 나뉘는 팀 모드입니다(클래식 규칙, 5판 3선승, 라운드 1:40, 라운드 중 부활 없음, 2라운드 뒤 공수 교대). 공격 팀 한 명이 폭탄을 들고, A·B 구역(수비 팀의 컴퓨터가 있는 곳) 안에서 멈춘 채 E를 3초 누르면 설치합니다. 설치 35초 뒤 터지면 공격 승입니다. 수비 팀은 폭탄 1.5 m 안에서 E를 5초 눌러 해체하면 이깁니다. 설치 전에 공격 팀이 전멸하거나 설치 없이 시간이 끝나도 수비 승, 수비 팀이 전멸하면 공격 승입니다. 폭탄을 든 사람이 쓰러지면 그 자리에 떨어지고 공격 팀원만 주울 수 있습니다.
- **좀비 물량 막기**: 최대 4명이 한 편이 되어 스테이지마다 몰려오는 좀비를 막습니다(연습장에서 혼자, 멀티에서 방을 만들어 함께). 탄창은 스테이지 사이에 이어지고 예비 탄창은 다른 모드의 3배입니다. 스테이지를 깰 때마다 카드 160장 중 3장이 나오고(다시 뽑기 1번) 1장을 골라 강해집니다. 5스테이지마다 보스(10종 중 무작위, 스킬 사용)가 나오고 50스테이지부터 2마리, 100스테이지부터 3마리입니다. 쓰러진 사람은 다음 스테이지에 일어나고, 모두 쓰러지면 끝입니다. 목표는 가장 오래 살아남기입니다.
- **무기 교체**: 팀전과 폭파 미션은 라운드가 시작되기 전 대기 시간(5초)에 "N 을 눌러 무기 교체!"가 뜹니다. N을 누르면 가진 무기 목록이 열리고, 무기를 누르면 바로 바뀌며 창이 닫힙니다. 시작 전까지 몇 번이든 다시 바꿀 수 있고, 고르지 않으면 지난 라운드의 무기로 나갑니다. 개인전은 출격 전에 무기 선택 화면이 뜹니다.
- **팀 채팅**: 팀전과 폭파 미션의 경기 채팅에는 전체·팀 탭이 있습니다. 팀 채팅은 같은 팀에게만 보입니다.
- **즉시 부활**: 개인전에서 죽어 부활을 기다리는 동안 E를 누르면 3초를 기다리지 않고 바로 나옵니다(휴대폰은 '부활' 버튼). 한 번에 킬 한 번 값을 냅니다(멀티 10 P · 연습장 5 P). 결과 화면에 "즉시 부활 ×N"으로 보입니다.
- **16인방**: 방을 만들 때 최대 16명(팀전·폭파 미션 8:8)까지 고릅니다. 기본은 8명입니다. 맵 스폰보다 사람이 많으면 스폰 옆 빈자리에 나란히 섭니다.
- **이름표**: 머리 위 닉네임은 같은 팀에게만 보입니다. 적(개인전은 모두)은 이름 없이, 부활 보호 중일 때만 🛡가 보입니다.
- **움직이는 지형**: 좁은 맵에는 길을 오가는 엄폐물, 2층으로 오르내리는 리프트, 열렸다 닫히는 셔터가 있습니다. 위에 서면 같이 움직이고, 길에 서 있으면 밀려납니다. 모든 사람 화면에서 같은 자리에 있습니다.
- **문**: 코인 노래방과 한옥 민박에는 가까이 가면 옆으로 열리는 문이 있습니다. 닫혀 있으면 건너편이 보이지 않고 총알도 막힙니다. 누군가 문 가까이에 있는 동안에는 닫히지 않습니다.
- 라이플은 머리에 맞으면 거리와 상관없이 1발에 죽습니다.
- 상점 가격이 1,200 P 이상인 프리미엄 총은 예비 탄약이 무제한이고, 나머지 총은 탄창 + 예비 2탄창이 전부입니다.
- G를 누르면 손에 든 주무기·보조무기를 버립니다(칼로 바꿔 더 빨리 달릴 수 있습니다). 총을 든 채 죽으면 그 총이 떨어지고, 그 칸이 빈 사람이 닿으면 주워서 남은 탄약 그대로 씁니다. 휴대폰은 무기 칸을 길게 누릅니다.
- 저격총은 손끝이나 발에 맞으면 반샷이라 죽지 않습니다.
- 적을 잡고 5초 안에 또 잡으면 연속 킬입니다. 더블 킬 → 트리플 킬 → 쿼드라 킬 → 펜타 킬 → 헥사 킬, 그다음부터는 "당신은 전설입니다"가 그림·안내 음성과 함께 나옵니다. 죽으면 처음부터 셉니다.
- 경기와 비밀 스팟으로 포인트를 모아 상점에서 무기와 이모트를 삽니다. 예: 2단 줌 저격총, 연사형 라이플, 저반동 헤드라인 라이플, 셀카 이모트.
- 이모트 휠(B) 8칸에 무엇을 둘지는 상점의 이모트 탭에서 고릅니다.
- 처음에는 기본 캐릭터(보병)로 시작하고, 상점의 캐릭터 탭에서 포인트로 정찰병·공병·통신병·사막 레인저·야간 작전병·중장갑병(300~2,000 P)을 사서 입습니다. 모양만 다르고 몸 크기와 판정은 모두 같으며, 전투복은 팀 색이라 어느 캐릭터든 팀이 잘 보입니다. 다른 사람에게도 내 캐릭터로 보입니다.

## 배포

**GitHub Pages**: `main`의 루트를 그대로 배포합니다. 빌드 과정은 없고, `main`에 올리면 1~2분 뒤 반영됩니다.

**Supabase**: 멀티플레이와 전역 닉네임 중복 검사에 씁니다. 운영 프로젝트는 서울 리전의 `skala-fps`이고, 절차는 [docs/SUPABASE_SETUP.md](docs/SUPABASE_SETUP.md)에 있습니다. `js/config.js`를 비우면 연습장만 오프라인으로 동작합니다.

**중계 서버**: [server/relay](server/relay/README.md)의 Cloudflare Worker + Durable Objects(로비 하나, 방마다 하나)가 멀티 메시지를 Supabase Realtime 대신 중계합니다. 서버가 프레임을 받는 사람에게 직접 나눠 주므로 Supabase 무료 한도에 묶이지 않습니다. 배포 설정은 이 서버(`https://skala-relay.skala-fps.workers.dev`)를 씁니다(`js/config.js`의 `transport: 'relay'`, `'supabase'`로 바꾸면 Supabase Realtime으로 돌아갑니다). 판정은 지금처럼 방장 브라우저가 합니다. 배포와 전환 절차는 [docs/CLOUDFLARE_SOP.md](docs/CLOUDFLARE_SOP.md)에 있습니다.

**건의함**: 메인 메뉴와 일시정지의 **건의하기**에서 플레이어가 운영자에게 버그·제안·밸런스 의견을 바로 보냅니다. 운영자만 Supabase 대시보드에서 읽고, 답을 달면 보낸 사람의 건의함에 보입니다. 설계와 운영 방법은 [docs/FEEDBACK.md](docs/FEEDBACK.md)에 있습니다.

**전체 공지**: 운영자가 운영자 패널(`dev/notice.html`)에서 보낸 공지가 게임 화면을 열어 둔 모든 사람의 화면 맨 위에 뜹니다. 받는 화면이 서명을 확인하므로 운영자 열쇠가 없으면 보낼 수 없습니다. 사용법과 열쇠 관리는 [docs/NOTICE.md](docs/NOTICE.md)에 있습니다.
